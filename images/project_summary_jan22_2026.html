GONDOLA V2.0

Architecture Redesign for Cheap Models

Major Update
January 22, 2026

The Problem

Cheap models (Qwen, Gemma) were unusable on large projects. They would loop endlessly, explode context windows, and never complete tasks.

Before This Update

Qwen would run 48+ turns, take 7+ minutes, read every file in the project, and never call done(). Context payloads hit 600KB+. The agent was effectively broken for real-world use.

The Solution

A complete architecture overhaul focused on intelligent context management and model-specific optimizations.

Project Index System

Compressed project understanding in ~1000 tokens. Scans files once, extracts summaries and symbols, caches to .gondola_index.json. Task-aware file retrieval.

Context Manager

Token-aware context building with automatic compression. Large tool results get summarized. Stays under model limits without losing critical info.

Agent State Tracking

Tracks files read, tools called, turn count. Prevents duplicate reads, detects loop patterns, records task completion.

Model Capability Flags

Per-model configs: native_function_calling, max_agent_turns, checkpoint_turns, context_limit. Models get tailored handling.

Dynamic System Prompts

Prompts rebuilt each turn with project context, turn awareness, and files-already-read reminders. Model-specific guidance sections.

Checkpoint Injection

At configured turns (5, 10, 13), reminder messages are injected: "You have enough info. Call done() now." Forces completion.

Model-Specific Fixes

Qwen 3 235B

  • Explicit stopping criteria in prompt
  • Checkpoints at turns 5, 10, 13
  • Hard stop at turn 15
  • "Follow Instructions Exactly" section
  • "Always Check In When Finished" reminder
  • Narration instructions for user visibility

Gemma 3 27B

  • Text-based tool call parsing (no native FC)
  • Hallucinated output interception
  • Placeholder content detection
  • Stricter write_file validation
  • Checkpoints at turns 3, 6, 8
  • Max 10 turns

Key Concepts

Task-Aware File Retrieval

When user says "add a toggle to the settings menu", the ProjectIndex identifies only the relevant files (settings.py, ui/settings_panel.js, config.py) instead of loading the entire codebase. ~2000 tokens instead of 50000.

Checkpoint System

At configured turn thresholds, the system injects a reminder: "Turn 5: Review your progress. Do you have what you need? If yes, call done()." This breaks infinite exploration loops.

Duplicate Read Prevention

AgentState tracks every file read with content hash. If model tries to read same file again, it gets a cached response: "You already read this file. Contents unchanged." Prevents Qwen's loop behavior.

Results

  • Qwen completes tasks in 6-7 turns instead of 48+
  • Response time dropped from 7+ minutes to ~65 seconds
  • Context payloads reduced from 600KB to ~25KB
  • Models understand 100-file projects in ~1000 tokens
  • Gemma placeholder hallucinations detected and rejected
  • Workspace persists across server restarts
  • "Add toggle to settings" style tasks now work reliably

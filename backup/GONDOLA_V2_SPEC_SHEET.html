Gondola v2.2 Necromancer Edition

Stateless. Resilient. Atomic. Agent Architecture.

I. Core Philosophy

1. Resurrection over Persistence

Assume the process will die. Store cognitive state in the filesystem's "shadow" (Git) rather than volatile RAM.

2. Stateless Structuralism

Zero-latency file mapping using Tree-sitter and Ctags instead of a long-running Language Server (LSP).

3. Surgical Autopsy

Spawn deep-analysis workers (Jedi) only on-demand. SIGKILL immediately after results are returned.

4. Passive Safety

Fire-and-forget background diagnostics (Ruff) injected into the next turn's observation portal.

II. Cognitive Persistence (The Heartbeat)

venice/persistence.py Atomic Git Plumbing
  • Branch: _gondola_shadow (Hidden from user git branch by default).
  • Mechanism: Uses git commit-tree and git update-ref.
  • Safety: Never performs a checkout. Does not clobber user's working directory.
  • Payload: Encodes {thought: str, task: str} into the commit message history.
  • Resurrection: CLI reads the most recent commit on _gondola_shadow at startup to rebuild prompt context.

III. Structural Awareness Engine

venice/tools/undead_ops.py Tree-Sitter v0.25.2

get_skeleton(filename): Parses file into Classes/Methods with 100% accurate line-range mapping. Zero RAM idle cost.

symbol_jump(name): Greps .gondola_tags (Ctags) for instant cross-project definition leaps.

venice/undead_manager.py Lazy LSP (Jedi)

inspect_type(filename, symbol): Spawns a temporary Jedi process to perform deep type-inference and docstring lookup.

cleanup(): Surgical workers are terminated immediately after the tool call returns.

IV. Passive Safety & Diagnostics

The Observation Portal

Every write_file or edit_file triggers a background subprocess:

ruff check --format json > .gondola_diagnostics.json 2>/dev/null &

At the start of every turn, the CLI reads this JSON. If errors exist, they are injected as SYSTEM OBSERVATIONS before the agent speaks.

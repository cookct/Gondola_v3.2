Core Features

Persistent Memory

Session history, project notes, and user preferences persist across conversations in .venice_memory.json.

Automatic Backups

Every file edit creates a timestamped backup in .venice_backups/. Full undo capability with restore_backup.

Workspace Sandboxing

Operations are confined to the workspace directory. Symlink modes: allow, deny, or follow.

Thread-Safe UI

Atomic printer operations with proper locking prevent output corruption in multi-threaded environments.

Web UI Option

Flask-based web interface in venice-web-ui/ for browser-based interaction with the agent.

Streaming Responses

Real-time SSE streaming with configurable timeouts. Extended timeouts for reasoning models.

│   ├── memory.py           # Persistent memory (notes, history, preferences)
│   │
│   ├── tools/
│   │   ├── schema.py       # 30 OpenAI-compatible function schemas
│   │   ├── file_ops.py     # File CRUD, search, info operations
│   │   ├── code_ops.py     # Syntax validation, function/class finding
│   │   ├── shell_ops.py    # Command execution, environment handling
│   │   └── base.py         # CombinedTools aggregator
│   │
│   └── prompts/
│       └── system.py       # Core system prompt with directives
│
├── venice-web-ui/
│   ├── server.py           # Flask web server
│   ├── templates/          # HTML templates
│   └── static/             # CSS, JS assets
│
├── .venice_memory.json     # Persistent memory store
├── .venice_backups/        # Automatic file backups
└── app_config.json         # API keys, settings

Usage

# Start CLI with default workspace
python -m venice.cli

# Specify workspace and model
python -m venice.cli -w /path/to/project -m claude-opus-45

# Start web UI
cd venice-web-ui && python server.py

# Quick start script
./start_gondola.sh
